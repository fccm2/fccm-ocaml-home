tut-mgk-gen

There are two version for mgk-gen, the first one mgk-gen wraps the magick-core version 6, and mgk-gen2 wraps the version 7 of the magick-core.

After you installed it you should be able to run your script with:
\ocaml -I +magick magick.cma script.ml.

There are two interfaces, the low-level interface (low), and the high-level interface (high).

Both are named: Magick. The second one is inside the first one.

The low-level interface can be started with:

Magick.magick_core_genesis () ;;

And the other one can be initialised by:

open Magick

With the low-level interface, an exception_info and an image_info, can be respectivelly acquired and cloned by:

  let e = Magick.magick_exception_info_acquire () in
  let nf = Magick.magick_image_info_clone () in

In the high-level interface:

open Magick
let () =
  let img = Magick.image_read "./some.png" in
  Magick.image_display img;
;;

And the methods that can be applied to the loaded image are: doc-high.
